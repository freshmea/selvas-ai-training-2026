# 1일차 · 제품번호 하나로 시작하는 데이터 실습

**준비:** [기본 CSV](../samples/products.csv), [정제 CSV](../samples/products-cleaning.csv), [PBL 기록지](../worksheets/day01-pbl.md).
두 CSV는 서로 다른 실습본입니다. 먼저 기본 CSV를 사용합니다.

## 1. 첫 문의 해결

“000123의 모델과 Main 버전을 알려주세요.”
Google Sheets로 기본 CSV를 가져올 때 자동 숫자 변환을 끄고 제품번호를 문자열로 보존합니다. 가져온 뒤 수식 입력줄에서 `000123`이 유지되는지 확인합니다. 이미 `123`으로 바뀌었다면 서식만 고치지 말고 원본을 다시 확인합니다.
답과 함께 파일·탭·제품번호·필드·소요시간을 기록합니다.

## 2. 검색 실패 실험

같은 전체 일치 조건에서 `000123`과 `123`을 각각 찾아봅니다. 두 결과가 달라지는 이유를 설명합니다. 새로운 정상 번호와 `DEMO-9999`도 시험합니다.

## 3. 공백과 중복 실험

정제 CSV를 별도 시트로 열고 원본을 보존합니다. 작은 실험용 탭에 다음 두 행을 만듭니다.

| A: 원본번호 | B: 정제번호 | C: 일치건수 |
| --- | --- | --- |
| 앞뒤 공백을 넣은 DEMO-0006 | `=TRIM(A2)` | `=COUNTIF($B$2:$B$3,B2)` |
| DEMO-0006 | `=TRIM(A3)` | `=COUNTIF($B$2:$B$3,B3)` |

A3을 DEMO-0007로 바꾸었다가 복원하며 건수가 어떻게 달라지는지 관찰합니다. 이 작업은 가상 실험이며 실제 제품번호를 바꿔 중복을 숨기는 해결책이 아닙니다.
공백 정리 뒤 같은 키가 되었어도 충돌하는 다른 필드를 확인해야 합니다. TRIM은 모든 특수 공백을 처리하지 않으며 COUNTIF는 대소문자를 구분하지 않습니다.

## 4. 새로운 질문에 적용

“DEMO-0004의 출고일도 알려주세요.” 필요한 열, 조회 조건, 빈칸일 때의 답변을 정합니다. 정상·미등록·누락의 세 경우를 시험합니다. 누락 상황은 별도 가상 사본에서 만듭니다.
Workspace Studio에 접근 가능하면 강사 안내에 따라 연결 실습을 진행합니다. 접근이 막히면 입력·조건·작업·결과를 설계하고 수동 대조까지 수행합니다.

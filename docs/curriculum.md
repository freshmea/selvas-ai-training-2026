# 5일 학습 로드맵

외부 코칭 5일 × 4시간 = 20시간 운영안입니다. 기존 전체 계획의 사내 보안·윤리 및 최종평가 4시간은 별도입니다.
1일차 운영 예정일은 2026-10-14이며 실제 진행 여부는 강사 공지를 따릅니다. 2~5일차 날짜는 작성 예정입니다.

| 일차 | 해결할 문제 | 실습 결과 |
| --- | --- | --- |
| 1일차 | 검색 실패와 중복의 원인을 어떻게 찾을까? | 문제정의·데이터 규칙·실험 기록 |
| 2일차 | 자연어 질문에서 정확한 제품 행을 찾을까? | Serial·항목 추출, 0·1·여러 행 구분 |
| 3일차 | Chat에서 질문하고 결과를 받을까? | 질문→조회→답장 흐름과 원천 대조 |
| 4일차 | 답이 없는 문의를 어떻게 넘길까? | 예외 분류·티켓 기록·담당자 인계 |
| 5일차 | 다른 사람이 써도 믿을 수 있을까? | 교차 시험·개선·운영 안내·발표 |

1일차 자료와 NotebookLM 보충 자료부터 제공합니다. 2~5일차 상세 교안은 작성 예정입니다.
NotebookLM 보충 실습은 권장 120분(활동 110분·휴식 10분)이며 5일 과정 시간에 자동 합산하지 않습니다.

## 매일 남길 기록

문제 → 가설 → 예상 결과 → 실제 관찰 → 원천 근거 → 다음 행동.
자동 실행을 하지 못했다면 수동 대조 또는 설계까지 완료한 사실을 구분합니다.

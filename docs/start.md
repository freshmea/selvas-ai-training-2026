# 시작 안내

## 수업 전 준비

- [ ] 노트북과 웹 브라우저를 준비합니다.
- [ ] 수업에 사용할 Google 계정으로 로그인합니다.
- [ ] Google Drive·Sheets와 승인된 Cloud Agent Designer 실습 환경을 확인합니다.
- [ ] Cloud 프로젝트·제작 권한·자료 접근·모델 한도를 확인합니다. Workspace Studio는 사용하지 않습니다.
- [ ] 배포 ZIP을 내려받고 원본과 개인 실습본을 구분합니다.
- [ ] 질문을 남길 경우 GitHub 계정을 준비합니다. 자료 열람에는 로그인이 필요하지 않습니다.

## 두 공간 사용하기

| 공간 | 하는 일 |
| --- | --- |
| 노션 | 수업 안내, 일차별 길찾기, 자료 링크 |
| GitHub | 자료 다운로드, 수정 이력, 가상 데이터 질문 |
| 개인 Google Drive | 본인의 실습 시트와 활동 결과 |

교육자료의 날짜·강의실·제출 마감은 강사 공지를 기준으로 합니다. 미확정 일정은 작성 예정입니다.
서비스 접근이 되지 않으면 오류 화면의 계정 정보를 가린 뒤 질문에 적습니다. 설계·수동 대조·자동 실행을 나누어 기록합니다.

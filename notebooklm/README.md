# NotebookLM × Google Drive

문서에서 답을 찾고 인용을 대조한 뒤 원문 변경이 소스와 새 답변에 반영되는지 확인합니다. 권장 120분의 보충 실습입니다.

**[등록 순서](sources/등록순서.md)** · **[질문 10개](prompts.txt)** · **[활동지](../worksheets/notebooklm.md)**

## 실습 순서

1. `sources`의 01·02·04 TXT 본문으로 본인 Drive에 Google Docs를 각각 만듭니다.
2. 새 노트북에 01·02 Docs를 Drive 소스로 등록하고 03 TXT를 파일로 추가합니다. 계정에서 파일 업로드가 지원되지 않으면 복사한 텍스트로 등록하고 경로를 기록합니다.
3. 질문 파일의 공통 지시와 P01을 입력합니다. 인용을 열어 제품번호·값·문맥을 직접 비교합니다.
4. P02~P07로 누락·미등록·앞자리 0·중복·설치 버전과 배포 버전을 시험합니다.
5. [갱신 미션](sources/05_갱신미션_소스등록금지.txt)에 따라 기존 FAQ Docs를 V2로 변경하고 P08을 새로 질문합니다. 자동·수동 갱신·재등록·미확인을 구분합니다.
6. 04 연락체계 Docs를 검색·선택해 추가하고 P09·P10으로 답변 변화와 확인 요청 초안을 기록합니다.

## 소스로 넣는 자료

01 제품등록대장, 02 FAQ, 03 변경공지, 04 연락체계만 소스로 등록합니다. 질문·활동지·진행 지시·갱신 미션은 등록하지 않습니다.
NLM 가상 데이터는 1일차 DEMO CSV와 다른 데이터 세트입니다.
이 실습의 결과는 자료 검색과 요청 초안입니다. Chat 전송·티켓 저장 여부는 별도 실행 근거로 확인합니다.
계정에 따라 화면과 기능이 다르면 관찰한 상태를 활동지에 남깁니다.

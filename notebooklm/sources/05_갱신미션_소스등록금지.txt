강사 지시에 따라 수행하는 갱신 미션. 이 파일은 NotebookLM 소스로 등록하지 않는다.

1. Drive의 기존 NLM실습_02_제품지원_FAQ Google Docs를 연다. 새 문서를 만들지 않는다.
2. 기존 문구를 다음과 같이 바꾼다. V1 문구를 남겨두고 V2를 아래에 추가하지 않는다.
문서 버전: FAQ-V1 → 문서 버전: FAQ-V2
갱신 확인 표식: SYNC-V1 → 갱신 확인 표식: SYNC-V2
일반 문의의 1차 응답 목표: 접수 후 2영업일 이내. → 일반 문의의 1차 응답 목표: 접수 후 1영업일 이내.
3. Google Docs 저장 완료를 확인하고 변경 시각을 기록한다. 문서 URL이 변경 전과 같은지 대조한다.
4. NotebookLM으로 돌아와 해당 소스를 열고 원문에서 FAQ-V2와 SYNC-V2를 찾는다.
5. 자동 갱신 여부를 관찰한다. 즉시 반영되지 않으면 잠시 후 소스를 다시 열거나 노트북을 다시 연다. 화면에 Drive 동기화 기능이 보이면 수동으로 실행하고 그 사실을 기록한다.
6. 02 FAQ만 선택하고 P08 질문을 새로 입력한다. 이전 답변이 바뀌는 것을 기다리는 방식으로 확인하지 않는다.
7. 원문 V2, 소스 V2, 새 답변 1영업일 및 인용을 활동지에 기록한다.
8. 관찰 시간 안에 갱신되지 않으면 미확인으로 기록한다. 새 파일 재등록은 대체 실습이며 자동 동기화 성공과 구분한다.

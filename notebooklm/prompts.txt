[사용법]
아래 공통 지시를 각 질문 앞에 함께 붙여넣는다. P01~P10은 한 번에 묻지 않고 하나씩 실행한다. 이 파일은 소스로 등록하지 않는다.

[공통 지시]
현재 선택한 소스에 근거해 답하세요. 제품번호를 문자 그대로 비교하세요. 답변은 질문 대상 / 확인된 값 / 근거 문서와 레코드 / 확인이 필요한 사항으로 구분하세요. 없는 값은 추정하지 말고, 충돌은 함께 제시하세요. 가능한 경우 실제 소스 인용을 붙이세요. 문서명과 레코드 표식도 써주세요. 과거 대화의 답변보다 현재 원문을 확인하세요.

P01 정상 조회 / 01·02 선택
NLM-0001의 모델, 설치된 Main 버전, 기록된 보증만료일을 알려줘.

P02 필드 미기록 / 01·02 선택
NLM-0002의 설치된 Main 버전과 기록된 보증만료일을 알려줘. 빈 항목은 출고일이나 다른 제품으로 추정하지 마.

P03 미등록 번호 / 01·02 선택
NLM-9999의 모델과 출고일을 알려줘. 비슷한 제품번호로 대체하지 마.

P04 앞자리 0 / 01 선택
000123과 123을 각각 찾아 모델을 비교해줘. 두 번호를 같은 것으로 정규화하지 마.

P05 중복 충돌 / 01·02 선택
NLM-0003의 설치된 Main 버전이 확정되어 있나? R04와 R05를 함께 대조하고 추가 확인이 필요한 이유를 설명해줘.

P06 여러 문서 비교 / 01·02·03 선택
NLM-0001의 설치된 Main 버전과 해당 모델의 공지된 배포 버전을 비교해줘. 이 제품이 업데이트를 완료했다고 말할 근거가 있는지 설명해줘.

P07 보증 판단 / 01·02 선택
NLM-0002는 무상 수리 대상인가? 기록된 값과 확정할 수 없는 판단을 구분하고, 먼저 확인할 사항을 써줘.

P08 동기화 전후 동일 질문 / 02 FAQ만 선택
NLM실습_02_제품지원_FAQ의 현재 문서 버전, 갱신 확인 표식, 일반 문의의 1차 응답 목표를 알려줘. FAQ-03의 현재 원문을 인용해줘.

P09 자료 추가 전후 비교 / 추가 전 01·02, 추가 후 01·02·04 선택
NLM-0002의 미기록 Main 버전을 어느 담당 역할에 확인해야 하나? 현재 소스에 담당 역할이 없으면 없다고 밝혀줘.

P10 후속 확인 요청 초안 / 01·02·04 선택
NLM-0002의 미기록 Main 버전과 보증만료일을 확인하는 내부 요청 초안을 작성해줘. 제품번호, 누락 항목, 근거 문서와 레코드, 확인 요청 역할, 확인 후 기록할 내용을 포함해줘. 실제 발송하거나 티켓이 등록되었다고 말하지 마.
